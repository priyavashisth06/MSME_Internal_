# MSMSE Project Suite

Welcome to the **MSMSE Project Suite** repository. This repository contains a collection of fundamental web development assignments and backend Python scripts designed to showcase frontend design, user interaction, and data management principles.

## 📁 Repository Structure

The project is organized into multiple standalone task directories:

```text

🚀 Projects Overview
1. Interactive Web Calculator (ques1 calculator/)
A fully functional, responsive, and visually polished web-based calculator.

Frontend: Structured using semantic HTML5 and customized with dynamic styling variables.
Logic: Built using core JavaScript to handle standard mathematical operations seamlessly.

2. User Registration & Validation Form (ques2 form/)
A modern, user-friendly data submission form engineered with strict client-side verification.

Design Approach: Modeled based on specialized visual wireframes stored in the figma/ directory.
Validation: Includes real-time input error handling using JavaScript to prevent incorrect format submission before sending data.

3. Book Management System (ques3 books/)
A clean, modular backend automation tool written in Python (book_management.py).

Core Functionality: Implements Data Structures to perform standard CRUD operations (Create, Read, Update, Delete) for keeping track of library resources or book logs.
Execution: Run directly from the terminal using standard Python packages.

🛠️ Tech Stack Used
Frontend: HTML5, CSS3, JavaScript (ES6+)
Backend: Python 3.x
Tools & Linters: Web Hint Configuration (.hintrc), Figma for UI design reference
